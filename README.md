# SQL E-Commerce Data Analysis

## Objective

Perform SQL-based analysis on an e-commerce dataset to extract meaningful business insights, identify customer purchasing patterns, and evaluate overall sales performance.

## Tools Used

* SQL
* SQLite
* DB Browser for SQLite
* GitHub

## Dataset

The project uses an e-commerce sales dataset containing information about orders, products, customers, payment methods, coupon usage, referral sources, and order status.

## SQL Operations Performed

* SELECT statements
* WHERE filtering
* ORDER BY sorting
* GROUP BY aggregation
* Aggregate functions (COUNT, SUM, AVG, MAX, MIN)
* Business insight generation using SQL queries

## Analysis Conducted

* Total orders analysis
* Average order value analysis
* Product-wise sales analysis
* Payment method distribution
* Order status analysis
* Coupon usage analysis
* Referral source analysis
* High quantity order identification
* Most expensive order analysis

## Project Structure

* **data/** – Dataset used for analysis
* **queries/** – SQL project and query files
* **screenshots/** – Query results and analysis screenshots
* **analysis.sql** – SQL queries used in the project

## Key Insights

* Identified top-performing products.
* Analyzed customer payment preferences.
* Evaluated order completion and cancellation trends.
* Measured coupon usage impact on sales.
* Examined referral source effectiveness.
* Generated business insights from transactional data.

## Conclusion

This project demonstrates how SQL can be used to analyze e-commerce data efficiently and transform raw information into actionable business insights through structured queries and data exploration.
